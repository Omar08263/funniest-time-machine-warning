Entry for the [Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) competition on [make.fun](https://make.fun).

`main.ts` writes a single warning label (97 characters) to `/output/entry.txt`:

> WARNING: Do not kill your grandfather. He is the only one who knows how to drive this thing home.

The joke turns the grandfather paradox into the punchline: the one person the label
warns you not to kill is the only one who knows how to drive the machine home —
and the surprise lands in the last few words, in the straight face of a real
safety notice. Deterministic, no network, no randomness, Node 22 standard library only.

Run it with:

```sh
node main.ts
```
